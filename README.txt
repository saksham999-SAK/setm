# HackMatch Demo (HTML + CSS + JavaScript)

A front-end demo for presenting the HackMatch Hackathon Team Formation Platform.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No installation or server is required.

## Demo pages
- Discover: sample teammate cards, skill filters, compatibility scores, invite actions
- My team: dashboard, team members, roles, skill-gap panel, project overview
- Hackathons: sample events and event detail modals
- Invitations: received invitations, sent invitations, join requests, accept/decline demo interactions
- My profile: editable sample profile fields

## Important
This is a static front-end prototype. Data is sample data and actions are local UI simulations. No backend, real authentication, database, or actual invitation delivery is connected.
